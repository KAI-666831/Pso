# 快速收銀

離線也能用的收銀小工具。用 iPhone Safari 打開網址後「分享 → 加入主畫面」。

資料只存在手機裡，請定期在「設定 / 備份」備份。

## 雲端同步（Google 試算表）

1. 開一個新的 Google 試算表 →「擴充功能」→「Apps Script」
2. 刪掉原本內容，貼上 `google-apps-script.gs` 全部內容，改好老闆密碼和員工密碼
3. 「部署」→「新增部署作業」→ 網頁應用程式（執行身分：我／存取權：所有人）
4. 複製網址，到 App「設定 / 備份 → 雲端同步 → 我是老闆」貼上
5. 按「複製員工加入碼」傳給員工，員工在「我是員工」貼上
